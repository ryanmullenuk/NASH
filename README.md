# NASH Barber

First website concept for NASH Barber in Lymington, Hampshire.

**Live website:** [ryanmullenuk.github.io/NASH](https://ryanmullenuk.github.io/NASH/)

The site uses a bold editorial style with deep green, warm ivory and copper, combining modern British barbering with restrained Kurdish geometric influence. It is responsive and includes a full-width shop hero, branded loading sequence, subtle particle fields, scroll reveals, service icons, a complete price list, Kurdish barbering history, an original NASH customer gallery, opening hours, address, map, Google review summaries and a WhatsApp enquiry form.
